# `fms` Story


### What is this file/document for ?
- This markdown file is for two purpose
    1. Talk about how and why `fms` tool was built
    2. Use as a sample document to demonstrate functionalities of `fms`


### How is this document formatted ?
- Each heading which begins with three hashes `###` is a question and the points below it is an answer to it.
- Each heading/question has two blank lines before it. This unique attribute will be used to demonstrate some functionalities of `fms`.
- I will write this document in first person.


### When did the idea for `fms` first come in my mind ?
- While doing my M.Tech, I had a subject called seminar where I had to select a topic, read research papers for the same, find an open problem in the domain and finally write a report at the end of the semester.
- As the subject was quite different form regular subjects, I was getting lots of questions in my mind. Example:
    1. How many papers to read
    2. How to choose a guide and domain
    3. How will the evaluation happen
    4. And, many more...
- Whenever I would find a solution to any question, I would write them in a markdown file so that I can refer to them in future. So, I started writing all information relating to the subject in question and answer format.
- The difficulty I faced was - How will I know if I have any question already present in my notes or do I have to add it ?
    - Just like any school student, I generally am able to recall few keywords of question/answer/topic/paragraph/...
    - For this, I would require a searching technique which can find a line/paragraph provided I know few words and the searching tool should do searching on a range of lines
    - `fms` does the same 😃


### Why develop `fms` ?
- I did not find any other tool which could do what I wanted. And, even during my school days I had experienced situations where I would know the page on which the answer is, the side of the page (left or right), the column (first or second) and part of the page (top or bottom).
- I wanted a tool which can perform multi-word search and highlight all matches with different colours because colours always make things easy.
